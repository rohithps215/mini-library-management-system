# Mini Library Management System

## About the Project
The Mini Library Management System is a simple command-line application developed using Python. It helps manage books, borrowers, and borrowing records efficiently.

## Features
- Add new books to the library.
- Search for books by title.
- Borrow available books.
- Return borrowed books.
- Track borrowing and due dates.
- Identify overdue books.
- Display book summaries and borrowing history.
- Save book details and borrowing records to files.

## Technologies Used
- Python 3
- Lists and dictionaries
- Functions and conditional statements
- File handling using JSON and text files
- Date and time operations

## How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   `python newlib.py`

5. Follow the menu displayed in the terminal.

## Project Files
- `newlib.py` – Main Python program.
- `books.json` – Sample book data.
- `borrowing_records.json` – Stored borrowing records.
- `borrowing_records.txt` – Human-readable borrowing history
