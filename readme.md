# Mini Library Management System

## Overview
A command-line library management system developed using Python.

## Features
- Add and search for books
- Borrow and return books
- Track book availability
- Calculate due dates
- Identify overdue books
- Display library summaries
- Save borrowing records to a text file

## Technologies Used
- Python 3
- Lists and dictionaries
- Functions and control flow
- `datetime` module
- File handling

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run `python library.py`.

## Files
- `library.py` — Main program
- `books.txt` — Sample book data
- `borrowing_records.txt` — Saved lending history
- `obstacle_log.md` — Problems encountered and solutions
