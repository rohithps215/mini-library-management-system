# Obstacle Log — Mini Library Management System

## Problem 1: Adding books to the list
**Obstacle:** Initially, I faced errors while adding new books to the list.

**Solution:** I used the `append()` method to add each new book dictionary to the `books` list.

## Problem 2: Preventing duplicate borrowing
**Obstacle:** A book could be borrowed even when it was already checked out.

**Solution:** I added an availability check before allowing a book to be borrowed.

## Problem 3: Managing borrowing dates
**Obstacle:** Calculating due dates and identifying overdue books was challenging.

**Solution:** I used Python's `datetime` and `timedelta` modules to calculate due dates and check overdue books.

## Problem 4: Saving borrowing records
**Obstacle:** Borrowing records were lost when the program stopped running.

**Solution:** I used Python file handling with `open()` to save borrowing records in a text file.

## Conclusion
This project helped me understand Python dictionaries, lists, functions, conditional statements, loops, date handling, and file operations.
